- **Monday night:** the Grand Opening Gala (19:00–21:00) runs into the VAST & Cerebras nightcap (20:00–22:00) at Fatpour, right next to McCormick Place. Beowulf Bash (21:00–midnight) is up in Bucktown — a cab ride.

Field Museum and Adler Planetarium are a ~10-min walk apart on the Museum Campus (Petaflop also runs a free shuttle from McCormick); the River North venues (Lenovo, Arista, Oracle) are a cab ride away.
- **Wednesday afternoon:** the AWS booth reception (16:00–18:00), the Public Sector Gathering (16:00–17:30, Fatpour), and the Students & Early Career Reception (16:30–18:00) overlap.
- **Wednesday night is the second crunch:** WEKA's Taste of Chicago (shuttles from McCormick), A Night at the Museum, HPC Gala, Everpure, VAST × ByteBridge, Cisco's 200kW Happy Hour, and the Whiskey Society all start between 18:00 and 19:00. Fatpour, Cisco Studio, Chicago Oyster House, and Revel are all within a few blocks of McCormick Place.

## 🤖 Register with Claude (optional)

This repo includes a [Claude Code](https://code.claude.com/docs) skill, `/sc26-register`. It reads this list, asks which days and events you want, flags conflicts, and then fills in the RSVP forms in your own Chrome window. **It shows you each form and asks before clicking Submit.** You still handle logins, CAPTCHAs, and anything involving payment yourself.

1. Install the [Claude in Chrome](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome) extension.
2. Clone this repo, `cd` into it, and start Claude Code with browser tools: `claude --chrome` (needs a Claude subscription login, not an API key — see [the docs](https://code.claude.com/docs/en/chrome)).
3. Run `/sc26-register`, optionally with what you're after, e.g. `/sc26-register Tuesday night, anything with AMD or NVIDIA`.

**Only have the Chrome extension?** Open this list in Chrome (the website or this README), open the Claude side panel, and ask something like: *"Help me register for the SC26 events on this page that I can make on Tuesday. Show me what you filled in and ask before submitting each form."*

Without the browser tools connected, the skill falls back to a click-through checklist of your picks.
