## 🔎 Looking for a specific AI hardware / cloud company?

- **Cerebras** — only at the VAST Data nightcap (Mon 20:00, Fatpour, next to the convention center).
- **AMD** — the HPE Industry Reception at Adler Planetarium (Tue 19:00) is the AMD-branded social; no RSVP, badge only.
- **Google Cloud** — GCACC rooftop reception Mon 17:00 (register via the GCACC page). Google also mentions a joint reception with NVIDIA, but no public date/venue.
- **NVIDIA** — no standalone reception; find them at Petaflop (Tue), the MinIO Tiki Bar (Wed 14:00), and as co-sponsor of Oracle's (closed) reception.
- **AWS** — only the booth-level "Quantummania" reception (Wed 16:00, booth #4819), quantum-themed.
- **No SC26 reception found** (checked Nov 11): Intel, Groq, SambaNova, Tenstorrent, d-Matrix, Etched, Microsoft Azure, CoreWeave, Lambda, Dell, Supermicro.

## ⚠️ Scheduling collisions worth knowing

- **Monday night:** the two VAST Data events (20:00–22:00) fully overlap and are across town from each other (Spybar in River North vs. Fatpour next to McCormick Place), and both overlap the tail of the Grand Opening Gala (19:00–21:00). Beowulf Bash runs until midnight if you want a late option.
- **Tuesday night is the crunch:** Posters Reception, Lenovo, Petaflop, HPE/AMD, Arista, and Netris all overlap — realistically pick two. Field Museum and Adler Planetarium are a ~10-min walk apart on the Museum Campus; the River North venues (Lenovo, Arista, Oracle) are a cab ride away.
- **Wednesday:** the AWS booth reception (16:00–18:00) overlaps the Students & Early Career Reception in the same building; Everpure (18:30) chains nicely right after either one.

## 🤖 Register with Claude (optional)

This repo includes a [Claude Code](https://code.claude.com/docs) skill, `/sc26-register`. It reads this list, asks which days and events you want, flags conflicts, and then fills in the RSVP forms in your own Chrome window. **It shows you each form and asks before clicking Submit.** You still handle logins, CAPTCHAs, and anything involving payment yourself.

1. Install the [Claude in Chrome](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome) extension.
2. Clone this repo, `cd` into it, and start Claude Code with browser tools: `claude --chrome` (needs a Claude subscription login, not an API key — see [the docs](https://code.claude.com/docs/en/chrome)).
3. Run `/sc26-register`, optionally with what you're after, e.g. `/sc26-register Tuesday night, anything with AMD or NVIDIA`.

**Only have the Chrome extension?** Open this README in Chrome, open the Claude side panel, and ask something like: *"Help me register for the SC26 events on this page that I can make on Tuesday. Show me what you filled in and ask before submitting each form."*

Without the browser tools connected, the skill falls back to a click-through checklist of your picks.
